# OpiEesti Path Finder

This project helps students browse Estonian schools and programs.

## What was added

- Semantic HTML-first home page structure while keeping the same visual design.
- Data export pipeline for:
  - `kutsekoolid.csv`
  - `ulikoolid.csv` (includes universities + applied higher education)
  - `gymnaasiumid.csv`
  - MySQL import dump for XAMPP
- MySQL schema for easy import in phpMyAdmin.

## Data build commands

Run these from the project root:

```bash
npm run data:build
```

If Node/npm is not available, run the PowerShell generator directly:

```powershell
powershell -ExecutionPolicy Bypass -File .\\scripts\\build-school-data.ps1
```

Or generate only one format:

```bash
npm run data:csv
npm run data:sql
```

Outputs are written to `data/out/`:

- `kutsekoolid.csv`
- `ulikoolid.csv`
- `gymnaasiumid.csv`
- `schools_all.csv`
- `programs.csv`
- `opieesti_mysql_import.sql`

Latest generated snapshot contains 64 schools and 244 programs based on current in-repo datasets.

## MySQL (XAMPP) import

### Option 1: phpMyAdmin

1. Open phpMyAdmin.
2. Create/select database `opieesti`.
3. Import file `db/opieesti_mysql.sql`.

### Option 2: mysql CLI

```bash
mysql -u root -p < db/opieesti_mysql.sql
```

## Database files

- `db/schema.sql` - schema only
- `db/opieesti_mysql.sql` - full schema + data dump (generated by `npm run data:build`)
- `db/import.sql` - helper script for command line source workflow

## Notes

- Current exports are generated from in-repo school datasets in `src/data/`.
- If you need full national coverage for all schools in Estonia, plug official source data into the build script in `scripts/build-school-data.ts`.
